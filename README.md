# 📱 QR Code Toolkit | Generator & Image Scanner

[![Python](https://img.shields.io/badge/Python-3.9%2B-blue?style=flat-square&logo=python)](https://python.org)
[![Pillow](https://img.shields.io/badge/Image_Processing-Pillow-blueviolet?style=flat-square)](https://python-pillow.org/)
[![QRCode](https://img.shields.io/badge/QR-Generator-black?style=flat-square)](https://pypi.org/project/qrcode/)

> Python-powered QR code generation and decoding suite allowing developers to encode URLs, credentials, WiFi configurations, and plain text into high-resolution scannable QR images.

---

## 🎯 Features

- **Custom QR Generation:** Encodes URLs, contact vCards, WiFi login tokens, and alphanumeric data.
- **Configurable Dimensions & Error Correction:** Custom box sizes, border widths, and High (H) error recovery.
- **Direct Image Export:** Saves output into optimized PNG, JPEG, and SVG graphics.

---

## 🚀 Quick Execution

```bash
git clone https://github.com/mesumali-dev/qr-code-toolkit.git
cd qr-code-toolkit

pip install -r Requiremnt.txt
python main.py
```
